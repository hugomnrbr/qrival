# Q-Rival v50 — Correções v48 + Engajamento v49

Esta versão é uma **mesclagem real** da base corrigida da v48 com o sistema de engajamento da v49.

## Mantido/corrigido da v48
- Loja sem oval em volta dos avatares.
- Perfil sem diamante/ícone lateral.
- Caixa de QuizCoins abaixo do avatar removida; saldo continua no topo.
- Títulos resolvidos pelo nome/arte, sem IDs internos.
- Inventário com seletor de categoria.
- Botão de Conquistas no perfil.
- Partida com avatar + título + nome/pontuação e cronômetro central.
- Cronômetro baseado no relógio sincronizado do servidor.
- Emojis/reação com RPC/fallback/realtime.
- Acesso administrativo para role admin.
- Fundos de perfil visíveis atrás do conteúdo.
- Compartilhamento somente quando o jogador toca em Compartilhar.

## Engajamento
- Eventos, missões, liga, streak e torneios da v49.
- Administração pelo painel.

## Supabase
Para uma instalação limpa das correções, use `SUPABASE_V50_DEFINITIVO.sql`.
